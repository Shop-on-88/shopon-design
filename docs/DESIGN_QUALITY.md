모든 샘플은 만들기 전에 이 문서를 읽고, 완성 후 아래 체크리스트로 스스로 점검한다.

## 0. 만들기 전에 방향 다섯 줄

코드를 쓰기 전에 아래 다섯 줄을 먼저 정한다. 유행이 아니라 이 가게가 무엇을 파는지에서 끌어낸다.

1. 가게: 무엇을 누구에게 파는지 한 문장
2. 성격: 구체적인 단어 2~3개 (예: "묵직하고 정확한", "따뜻하고 수다스러운"). "깔끔한·모던한·세련된·프리미엄"은 모든 템플릿에 해당하므로 금지
3. 세계: 이 가게가 속한 장소나 재료 (금은방 → 벨벳·금고·저울, 국밥집 → 가마솥·김·나무 식탁). 배경 색조, 강조색, 그림이 여기서 나온다
4. 강조색 하나: 세계에서 가져온 색 1개. 화면의 몇 %만 쓴다 (주요 버튼, 선택 상태, 핵심 숫자 1개)
5. 주인공 하나: 화면에서 가장 공들인 한 가지 (그림, 상품 모습, 차트 중 하나). 나머지는 조용하게

## 1. 금지 — AI 티가 나는 것들

### 색과 표면
- 보라→파랑, 보라→분홍 그라데이션 배경·버튼·카드 → 단색 표면, 강조색은 의미 있는 곳에만
- 제목·숫자·로고에 그라데이션 글자 → 단색 글자
- 색이 번지는 발광 그림자, 빛나는 알약 버튼 → 제거. 깊이는 표면 단계와 얇은 테두리로
- 콘텐츠 뒤의 흐릿한 색 덩어리·원형 빛 번짐 → 제거
- 모든 요소를 강조해서 아무것도 눈에 안 띄는 상태 → 강조는 화면당 1~2곳

### 글자
- 제목 굵기 800~900 → 600~700, 크기로 위계를 만든다
- 영어 대문자 + 넓은 자간 라벨 남발 (예: "TODAY'S PRICE") → 한국어 보통 문장형 라벨. 영어 라벨을 쓰더라도 한 페이지 1~2곳만
- 한 화면에 크기·굵기 종류가 너무 많음 → 정해진 단계 몇 개만
- 숫자 형식이 섞임 → 한 형식, 숫자 폭 맞춤(tabular)
- 본문 16px 기준, 줄간격 1.5 이상, 최소 12px (BRIEF의 11px 하한보다 이 기준을 우선)

### 아이콘
- 이모지를 아이콘·장식·상태 표시로 쓰기 (🏠🚀💰🔥✨) → 선 아이콘 한 세트 또는 없음
- 아이콘 크기·두께·색이 제각각 → 한 크기, 한 선 두께
- AI 기능이라고 반짝이 ✨ 붙이기 → 제거

### 간격
- 4px 단위가 아닌 임의 값 (13px, 7px, 31px) → 4·8·12·16·20·24·32·40·48·64·80·96·128 중에서
- 같은 목록 안 행 높이·간격이 다름 → 하나로 통일
- 그룹 안 간격이 그룹 사이 간격보다 큼 → 안쪽은 좁게, 바깥은 넓게
- 섹션 간격: 일반 32~64, 랜딩 80~128

### 문구 (humanizer 원칙)
- 인사형 제목 ("어서 오세요! 👋") → 페이지가 무엇인지가 제목
- 느낌표·"!!" 남발 → 평서문
- 과장 단어: 혁신적인, 놀라운, 완벽한, 압도적인, 차원이 다른, 마법 같은 → 실제로 해 주는 일을 쓴다
- "A가 아니라 B입니다" 식의 강조 대비, 문단 끝마다 붙는 한 줄 결론, 억지 세 가지 나열 → 사실을 바로 쓴다
- 어떤 가게에 붙여도 말이 되는 헤드라인 → 이 가게만의 명사로 이 가게가 하는 일을 쓴다
- 버튼·라벨 끝 마침표 → 없음
- 가짜 같은 숫자 (123,456 / 00% / [X]) → 그럴듯한 숫자

### 구성 요소
- 헤드라인 위 알약 배지 ("✨ NEW 오픈!") → 제거, 진짜 소식이면 조용한 글자 링크
- 버튼 3개 이상 나열 → 주 버튼 1개 + 보조 1개까지
- "10,000명이 선택", 별점 다섯 개, 아바타 점 줄 (출처 없음) → 금지 (BRIEF와 같음)
- 모든 카드에 미니 그래프 → 숫자와 라벨만
- 똑같은 카드가 줄줄이 같은 모양 → 주인공 하나 + 크기를 달리한 보조
- 로고를 그라데이션 타일 + 반짝이로 → 이름 글자 + 단순한 단색 마크

### 첫 화면 (히어로)
- 모든 것을 가운데 정렬로 위에서 아래로 쌓기 → 좌우 비대칭 배치, 또는 큰 상품 화면 위에 글자
- 둥둥 떠다니는 구슬·격자·빛나는 선 배경 → 평평한 배경 또는 실제 상품 그림 하나
- 그림 가장자리가 딱 잘려 배경 검정과 다름 → 페이지 배경색과 맞추고 가장자리를 부드럽게
- 모든 섹션마다 그림 → 그림은 도움이 되는 곳에만, 보통 히어로 하나

### 움직임
- 살아 있는 정보가 아닌데 깜빡이거나 숨 쉬는 효과 (pulse, ping) → 정지
- 카드·버튼 hover 시 확대(scale) → 색이나 표면 단계 변화만
- 통통 튀는 애니메이션, 사방에서 날아 들어오는 요소 → 짧은 페이드+살짝 올라오기 한 종류
- width·height·top·left 애니메이션 → transform·opacity만
- prefers-reduced-motion 대응

## 2. 수치 기준

- 색 대비: 본문 글자 4.5:1 이상, 큰 글자·아이콘 3:1 이상
- 터치 영역: 모바일 버튼·링크 최소 44×44px
- 버튼 높이: 히어로 44~48px, 일반 36~40px
- 둥글기: 크기에 비례 (작은 요소 6~8, 카드 12~16, 큰 패널 20~24). 모든 것을 알약 모양으로 만들지 않는다
- 중립색은 세계에 맞춰 살짝 물들인다 (따뜻한 세계는 웜 그레이, 차가운 세계는 잉크 블루 그레이). 순수 회색 #161616 + 흰 글자 + 버튼 하나만 브랜드색 = 템플릿 느낌
- 이미지는 공간을 미리 잡아 둔다 (aspect-ratio). 아래쪽 이미지는 loading="lazy"

## 3. 완성 후 체크리스트

- [ ] 방향 다섯 줄을 정했고, 화면이 그 성격·세계와 맞는다
- [ ] 1번 금지 목록에 해당하는 것이 하나도 없다 (하나씩 찾아서 적고 고친다)
- [ ] 강조색이 화면의 몇 %만 차지하고, 주인공이 한눈에 보인다
- [ ] 이모지 아이콘 없음, 아이콘 한 세트·한 크기
- [ ] 간격이 4px 단계, 같은 종류끼리 같은 간격
- [ ] 문구에 과장·느낌표·인사형 제목·가짜 숫자 없음, 헤드라인에 이 가게만의 명사가 있다
- [ ] 390px 모바일에서 가로 넘침 없음, 터치 영역 44px 이상, 글자 12px 이상
- [ ] 대비 4.5:1 (본문) 확인
- [ ] 가게 이름만 바꿔 다른 업종에 써도 어색하지 않다면 실패 — 다시 방향부터
