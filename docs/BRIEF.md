# 샵온 디자인 샘플 2차 제작 공통 지침 (개발자 역할)

목적: "Shop On Design"(가게 홈페이지·메뉴판·광고 이미지 제작 서비스)의 판매용 샘플. 주 고객은 필리핀 교민 가게와 한국 국내 가게, 현지 가게 문의 대비로 일부는 영어판도 만든다.
품질 기준: 실제 디자인 에이전시 포트폴리오 수준. 평범한 템플릿 느낌이 나면 실패다.

## 공통 규칙
- 상호는 전부 가상. 실존 브랜드·프랜차이즈 이름, 로고, 대표 색 조합, 캐릭터, 문구를 쓰지 않는다. 다른 회사 SNS·결제 앱 로고처럼 보이는 아이콘도 쓰지 않는다(일반 선 아이콘 사용).
- 메뉴명·가격은 예시로 지어내도 된다(한국 가게는 원, 필리핀 가게는 ₱). 후기·별점·수상·"1위"·"BEST"·판매량 같은 실적 주장, 효능 단정 문구, 실제 전화번호·주소·사업자번호는 넣지 않는다. 연락처 자리는 "000-0000-0000", "카카오톡 ID: example" 같은 명백한 자리표시로.
- 결과물 안에 작업 설명·메모·작성자 이름을 넣지 않는다.
- 외부 이미지 금지. 음식·사람·공간 그림은 인라인 SVG 일러스트로, 그라데이션·그림자·질감을 넣어 고급스럽게. 같은 그림 반복 금지. 실존 인물을 닮게 그리지 않는다.
- 글꼴은 Google Fonts(Noto Sans KR, Noto Serif KR, Gowun Batang, Black Han Sans, Do Hyeon, Nanum Myeongjo, Playfair Display, Montserrat, Outfit 등 상업 무료)만.
- 한국어는 word-break: keep-all. 글자 넘침·잘림·겹침 없게. 가장 작은 글자 11px 이상(인쇄물은 인쇄 크기 기준 7pt 이상).
- 렌더링·캡처: python3 playwright, chromium.launch(executable_path='/usr/bin/google-chrome', args=['--no-sandbox']), document.fonts.ready 대기.

## 검수 (스스로 2회)
만든 뒤 캡처를 Read로 직접 열어 보고, 아래를 점검해 고친 다음 다시 캡처한다. 2회 반복.
- 넘침·잘림·겹침·빈 그림·어색한 빈 공간
- 같은 카테고리 안에서 샘플끼리 색·배치가 겹치지 않는지(각자 다른 스타일)
- 위 금지 문구가 없는지 (grep 으로 BEST, 1위, 인기, 후기, 별점 확인)

## 보고
마지막에 짧게: 만든 파일 목록과 경로, 각 샘플의 업종·스타일 한 줄, 스스로 부족하다고 보는 점. "완료"라고 쓰지 않는다.
